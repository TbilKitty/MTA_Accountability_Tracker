Evidence before conclusions.

Transparent definitions, preservation procedures, and data limitations make public accountability credible.

Research status: This project is developing its collection and verification methods. No reliability rate should be represented as validated until the underlying analysis is complete.

Methodology and definitions

Units

Use a unique observation key (service_date, trip_id, stop_id, scheduled_time); include direction, route, and source feed version. Account for GTFS times beyond 24:00 and the America/New_York timezone, DST transitions, service calendars, and exceptions. Do not conflate vehicle observations with passenger boardings.

Thresholds

  • Official MTA local-bus OTP benchmark: generally -2 to +7 minutes at scheduled timepoints (check current definition).
  • Project significant-delay threshold: >30 minutes. This is an analytical threshold, not a legal standard.
  • confirmed_cancellation: explicit provider trip cancellation or independently authenticated operational record.
  • suspected_no_show: rider report or inference requiring verification; never infer solely from missing GPS, predictions, or alerts.
  • confirmed_pass_by: corroborated passenger/stop evidence; vehicle GPS alone cannot prove boarding denial.
  • data_unavailable: feed outage, stale timestamps, failed API request, unmatched trip or vehicle; not a service failure.

Economic impacts

Report separately: (1) observed passenger-delay minutes where supported; (2) modeled time value, using explicit assumptions and sensitivity intervals; (3) self-reported work hours; (4) corroborated lost earnings; (5) accrued leave value; (6) additional actual expenditures; (7) employer incremental costs if documented. Never add overlapping valuations or assume all riders are employed. Avoid extrapolating from a convenience sample to all MTA riders without representative sampling.

Quality controls

Keep feed snapshot timestamps, checksums, original timezone, query parameters, provider response codes, schema versions, matched trip/stop IDs, observer identity in private records only, and any corrections. Track denominator: scheduled trips, successfully observed trips, and coverage hours. Publish methodology and confidence classification with every statistic.

Evidence and preservation protocol

  1. Archive unmodified source bytes, source URL, UTC retrieval time, SHA-256, HTTP status, and collection software version.
  2. Keep originals immutable; append corrected interpretations as new records, never rewrite raw evidence.
  3. Maintain a chain-of-custody log of collection, access, export, and transformations. Secure backups with restricted access.
  4. Keep rider reports private. Obtain informed consent and avoid publishing minors' names, school, precise stops, contact information, and regular travel times.
  5. Retain original screenshots and messages with timestamps and context; distinguish recollection from contemporaneous observation.
  6. Preserve failed requests and missing data as data gaps, not bus failures.
  7. Document corroboration and conflicting evidence; provide an error correction mechanism.
  8. Before using records in litigation, consult Maryland counsel about admissibility, authentication, discovery, preservation duties, potential public records requests, and statutes of limitations. The dataset alone does not establish legal duty, breach, causation, or damages.

Data dictionary

Rider report columns

  • report_id: random non-identifying unique ID
  • incident_date: local YYYY-MM-DD
  • route_id, stop_id: GTFS IDs; keep exact stop private for minor-related reports
  • scheduled_time_local, observed_time_local: HH:MM or blank
  • incident_type: late / no_show_reported / pass_by_reported / canceled_reported
  • verification_status: unverified / corroborated / disputed
  • work_hours_missed: nonnegative decimal
  • documented_wages_lost_usd: dollars, actual wage loss only
  • paid_leave_hours_used: hours, not automatically fiscal expenditure
  • extra_transport_cost_usd: dollars
  • school_minutes_missed: minutes
  • evidence_reference: private file ID, not public URL
  • notes_private: restricted narrative; no public export

Do not place minors' names, addresses, or phone numbers in CSV fields.
