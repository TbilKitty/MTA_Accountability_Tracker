Privacy policy

Baltimore Transit Accountability and the "MTA Tracker Archive" tool · Effective November 4, 2026

Who we are

Baltimore Transit Accountability is an independent, non-commercial public-interest research project that measures the reliability of Maryland Transit Administration (MTA) local bus service in Baltimore. It is not affiliated with the MTA or any government agency.

What this website collects

This website does not ask for, collect, or store personal information from visitors. It has no accounts, sign-ups, advertising, or tracking cookies. Pages are hosted by GitHub Pages, which may keep standard server logs (such as IP addresses) under GitHub's privacy statement.

The transit data published here comes from the MTA's public schedule and real-time vehicle feeds and is reported in aggregate by route and stop. It does not identify riders.

The "MTA Tracker Archive" Google sign-in

The project uses a Google sign-in application named "MTA Tracker Archive" for one purpose: to let the project's own automated collector save copies of raw MTA feed files into the project owner's own Google Drive, so the source data behind published results is preserved.

  • It is used only by the project owner. It is not offered to the public, and no one else signs in to it.
  • It requests only Google's drive.file permission, which allows access solely to files the tool itself creates. It cannot see, read, change, or delete any other file in the Drive.
  • It does not collect, use, share, sell, or transfer any Google user data. No data obtained through Google is used for advertising or shared with any third party.
  • The files it saves are copies of public MTA transit data and their checksums. They contain no personal information.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from the Google account's third-party access settings.

Contact

Questions about this policy can be raised by opening an issue on the project's GitHub repository.
